All terms are original coinages by **Hakeem Oluwafemi Adeniyan**.

🔗 **Live site:** [https://hakeemoadeniyan.github.io](https://hakeemoadeniyan.github.io)

---

## 📖 About This Project

The Yoruba language, spoken by over 50 million people, lacks standardized terminology for many modern concepts in science, technology, mathematics, economics, education, and general knowledge. This project addresses that gap by coining new Yoruba words following systematic linguistic principles.

Each entry includes:
- **The coined Yoruba term**
- **English meaning**
- **Formation explanation** (how the word was built)
- **Usage examples** with English translations
- **Date coined**
- **APA 7th edition citation** with one-click copying

This dictionary is built as a static site using **Jekyll** and hosted for free on **GitHub Pages**, ensuring fast, reliable, and permanent access.

---

## 🎯 Mission

To help Yoruba thrive in the modern world by providing a growing, citable, and freely accessible terminology resource for speakers, students, educators, researchers, and AI language models.

## 🗂️ Dictionary Structure

The dictionary is organized by subject areas:

| Subject | Examples |
| :--- | :--- |
| **Technology** | laptop computer, smartphone, internet |
| **Science** | photosynthesis, molecule, ecosystem |
| **Mathematics** | algorithm, variable, equation |
| **Education** | curriculum, pedagogy, assignment |
| **Economics** | demand, supply, production |
| **General knowledge** | pragmatic, ideal, real |

More subjects will be added as the dictionary grows.

## 📝 How to Cite a Term

Every dictionary entry page includes a citation box at the bottom. You can copy citations in two formats:

**Formatted citation (with italics):**
> Hakeem Oluwafemi Adeniyan (2026, June 7). *Kọ̀mpútà alágbèéká* (laptop computer). In *Yoruba Terminology Dictionary*. Retrieved from https://hakeemoadeniyan.github.io/dictionary/komputa-alagebeka/

**Plain text citation (for plain‑text environments):**
> Hakeem Oluwafemi Adeniyan (2026, June 7). "Kọ̀mpútà alágbèéká" (laptop computer). In "Yoruba Terminology Dictionary." Retrieved from https://hakeemoadeniyan.github.io/dictionary/komputa-alagebeka/

Simply click the "Copy" button and paste into your bibliography.
