english_meaning: "Algorithm"

author: "Hakeem Oluwafemi Adeniyan"
definition: >
  Ìlànà ìṣirò jẹ́ ọ̀nà ṣísẹ̀-n-tẹ̀lé tí a máa ń tẹ̀lé láti yanjú ìṣòro kan tàbí láti ṣe iṣẹ́ kan pàtó.
  Nínú ìmọ̀ ẹ̀rọ kọ̀mpútà, ìlànà ìṣirò jẹ́ àwọn ìtọ́sọ́nà tó ṣe gẹ́lẹ́ tí ẹ̀rọ kọ̀ǹpútà máa ń tẹ̀lé.
  (An algorithm is a step-by-step procedure followed to solve a problem or perform a specific task.
  In computer science, an algorithm is a set of precise instructions that a computer follows.)
formation: >
  A kó àsọyé yìí jọ láti ara ọ̀rọ̀ Yorùbá méjì: **Ìlànà** àti **ìṣirò**.
examples:
  - yoruba: "Ìlànà ìṣirò tó tọ́ máa ń yanjú ìṣòro ní kíákíá."
    english: "A good algorithm solves a problem quickly."
  - yoruba: "Àwọn olùkọ́ kọ̀ǹpútà ń kọ́ wa bí a ṣe lè kọ ìlànà ìṣirò."
    english: "Computer teachers teach us how to write algorithms."
  - yoruba: "Ìlànà ìṣirò yìí ní ìgbésẹ̀ márùn-ún."
    english: "This algorithm has five steps."
